# たつみ式 Claude Code 自動化キット（tatsumi-auto-kit）

顔出しなしYouTube・ショート動画・note・SNS の「調べる → 書く → 声 → 動画 → サムネ → 投稿文 → 振り返り」を、
Claude Code に話しかけるだけで進められるようにする、スキルと担当（サブエージェント）の一式です。

- エンジニアでなくても使えるように、すべて日本語の手順書（スキル）で動きます
- **作るのは、あなたのパソコンの中のファイルだけ**です。投稿・予約・アップロード・送信・支払いは、キットは一切しません
- 有料の API キーが無くても、最後まで動きます（声はパソコン内蔵の声になります）
- ライセンス：MIT（LICENSE を参照）

> 教科書『Claude Code × 完全自動化キット』第8章が、このキットの詳しい使い方です。

### 担当（サブエージェント）6人

| 担当 | 受け持ち |
|---|---|
| researcher | ネタ・競合のリサーチ |
| scriptwriter | 台本・note 記事・ショート台本 |
| editor | 声・動画・編集・切り抜き |
| thumbnail-designer | サムネ |
| publisher-drafts | 投稿文・説明文・予約の予定表（**下書きだけ**） |
| analyst | 振り返り・週報 |

「チームで1本作って」と頼むと、メインの Claude Code が担当に順番に仕事を回します。

## 2 フォルダの中身

```
tatsumi-auto-kit/
  README.md            このファイル
  CLAUDE.md            就業規則のひな形（【】を埋めて使う）
  LICENSE              MIT
  TESTS.md             動作確認の記録
  .env.example         キーの見本（キーは入っていない）
  .claude/
    settings.json      権限の鍵（秘密のファイルを読ませない・削除させない など）
    skills/            スキル14個
    agents/            担当6人
  scripts/
    kit_doctor.py      キットの健康診断（読むだけ）
    run_tests.sh       動作確認をまとめて実行
  samples/             見本（架空のチャンネル「ゆる家計ラボ」）
```

作ったものは、キットの外の **作業フォルダ（初期値 `~/kit-work`）** に置きます。キットを入れ替えても、作ったものは消えません。

## 4 セットアップ 10ステップ

1. **キットを手に入れる。** 【キットURL】から zip をダウンロードして展開するか、`git clone 【キットURL】` で取ってきます。
2. **置き場所を決める。** ホームの下に置くのがおすすめです（例：`/Users/あなたの名前/tatsumi-auto-kit`）。デスクトップやダウンロードのままでも動きますが、場所を動かすと CLAUDE.md の絶対パスを書き直す必要があります。
3. **ターミナルでキットのフォルダに移動する。** `cd ~/tatsumi-auto-kit`（Windows は `cd $HOME\tatsumi-auto-kit`）。
4. **Claude Code を起動する。** `claude` と打ちます。「このフォルダを信頼しますか」と聞かれたら、**自分で展開したキットであることを確かめてから**信頼します（信頼しないと `.claude/settings.json` の設定が効きません）。
5. **初期設定を頼む。** 「キットの初期設定をして」と話しかけます。道具の点検 → 作業フォルダ作り → 試し運転 まで、1段ずつ案内されます。
6. **足りない道具を入れる。** 案内されたコマンドを、**あなた自身が**ターミナルに貼って実行します。入れたらターミナルを開き直し、「もう一度点検して」と頼みます。
7. **スキルの使い方を選ぶ。** 迷ったら「C：キットのフォルダで使う」。いつもの作業フォルダで使いたい人は A か B を選ぶと、スキルと担当がコピーされます。
8. **Claude Code を開き直す。** `/exit` で終了して、もう一度 `claude`。新しいスキルはここで読み込まれます。
9. **CLAUDE.md を埋める。** 「CLAUDE.md の【】を一緒に埋めて」と話しかけ、テーマ・見てほしい人・フォルダの絶対パスを答えます。
10. **試しに1本。** 「固定費の見直しでネタを探して」→「候補1で台本を書いて」と進めてみます。うまく動かないときは「キットの初期設定をして」で点検をやり直せます。

## 5 毎日の使い方

### 1本の動画を作る日（目安：作業そのものは1〜2時間。確認の時間は別）

```
1 「◯◯でネタを探して」              → research/ にリサーチボード
2 「候補◯で台本を書いて」             → 構成にOK → script.json・factcheck.md
3 factcheck.md を自分で確かめる        ← ここは人の仕事
4 「ナレーションを作って」             → 1シーンだけ耳で聞く
5 「動画にして」                       → OK（長さ照合）を確認、最初と最後の10秒を見る
6 「サムネを作って」                   → 3枚から1枚選ぶ
7 「この動画から投稿文を作って」       → sns/ に下書き5本
8 YouTube Studio と各SNSの公式画面で、自分の手でアップロード・予約投稿
```

### 週のリズム（例）

```
月  リサーチ・台本            火  声・動画・サムネ        水  公開（自分の手で）
木  切り抜きショート3〜5本    金  note の下書き           土  投稿文の下書き1週間分
日  「週報を作って」→ 来週の作戦を自分で決める
```

## 6 お金がかかるもの（任意のものだけ）

キットそのものは、Claude の有料プラン以外にお金がかかりません。次は**使いたい人だけ**です。料金・無料枠は変わるので、使う前に必ず公式ページで確かめてください。

| もの | 何に使う | 無料で使えるか | 確かめる場所 |
|---|---|---|---|
| Claude の有料プラン | Claude Code を動かす（必須） | ― | https://claude.com/pricing |
| Gemini API（音声合成） | ナレーションの声を自然にする | 無料枠あり。1分・1日の回数に上限があり、長い動画は1日で作り切れないことがある | https://ai.google.dev/gemini-api/docs/pricing |
| whisper（手元で文字起こし） | 長い動画の字幕 | 無料（パソコンで動く） | https://github.com/openai/whisper |
| BGM・効果音 | 動画の音 | 無料素材サイトもある。利用条件を必ず読む | 各素材サイトの利用規約 |

- `ANTHROPIC_API_KEY` を環境変数に入れていると、プランではなく API の従量課金になることがあります。キットでは使いません。
- Gemini のキーが無い・上限に達したときは、自動でパソコン内蔵の声に切り替えて最後まで仕上げます。

## 7 安全のための決まり（キットが守ること・あなたが守ること）

**キットがしないこと**

```
投稿・予約投稿・アップロード・送信・コメント返信
自動いいね・自動フォロー・一斉DM（各SNSの規約でスパム扱い。凍結の原因になる）
課金・購入・支払い
ファイルの完全削除（settings.json で rm を禁止）
.env・~/.zshrc など秘密のファイルを読む（settings.json で禁止）
```

**あなたが守ること**

1. **AI が作ったものは、必ず自分で読んで・聞いて・見てから出す。** 特に数字・制度・固有名詞（factcheck.md）。
2. **他人のものを使わない。** 動画・画像・音楽・文章・声は、自分で作ったものか、利用条件を確かめたものだけ。切り抜きは自分の動画か、許可をもらった動画だけ。
3. **量産・使い回しをしない。** YouTube は「大量生産・繰り返しの多い」コンテンツや「再利用されたコンテンツ」を収益化の対象外にしています。毎回、自分の体験・自分で作った比較や手順を入れます。
4. **AI を使ったことを隠さない。** 本物と見分けがつかない合成をしたときは、各サービスのルールに沿って表示します。
5. **キーをチャットに貼らない。** 貼ってしまったら、発行元の画面で削除して作り直します。
6. **確認を全部外す起動方法（`--dangerously-skip-permissions`）は使わない。**

## 8 困ったとき

| 症状 | まずやること |
|---|---|
| スキルが反応しない | Claude Code を開き直す / `/スキル名` で名指しする（例 `/yt-script`） |
| 「見つかりません」と出る | ターミナルを開き直したか / パスが絶対パスか |
| 動画が NG になる | 点検の全文を要約せずに Claude Code に見せる。「NG の理由を説明して直して」 |
| 字幕が □ になる | 日本語フォントが無い。`--font-bold` などでフォントファイルを指定 |
| 何がおかしいか分からない | `python3 scripts/kit_doctor.py` と `bash scripts/run_tests.sh` の結果を、そのまま購入先のサポートに送る |
