# yt-research（ネタ・競合リサーチのスキル）

調べて、出典つきの候補一覧をファイルにするだけのスキルです。
台本・記事・投稿文は書きません（次の yt-script / note-article / sns-post の仕事です）。
相手はエンジニアではありません。短い文で、専門用語を使わずに話してください。

以下 `$S` は、このファイルと同じフォルダの `scripts/` の絶対パスです。
作業フォルダ（以下 `$W`）は CLAUDE.md の「フォルダの地図」に書かれた絶対パスです（初期値 `~/kit-work`）。

---

## 流れ（1段ずつ。各段の終わりに短く伝える）

```
1 準備        テーマ・見てほしい人を確かめる。過去のリサーチと重なっていないか見る
2 ボード      research_board.py new で空のボードを作る
3 調べる      3つの切り口 × 3件以上。公式・本人の発信を優先
4 競合を見る  伸びている動画の「切り口」と「型」だけを見る（文章・映像は写さない）
5 候補を書く  10個。1つに5項目
6 点検        research_board.py check が NG 0 になるまで直す
7 渡す        保存場所・おすすめ3つ・確かめきれなかったこと
```

## 1 準備

- テーマが無ければ「どんなテーマで調べますか」と1回だけ聞く。
- `$W/memory/MEMORY.md` があれば読み、避けること・決めたことを確かめる。
- `$W/research/` のファイル名を一覧し、最近（30日以内）同じテーマを調べていたら、続けるか聞く。

## 2 ボードを作る

```
python3 $S/research_board.py new --theme "<テーマ>" --out $W/research
```

## 3 調べる

- ウェブ検索で「よくある悩み」「よくある間違い」「最近の変化」の3つの切り口を、それぞれ3件以上読む。
- 情報源の優先順：公式サイト・公的機関 → 本人の発信 → 大手メディア。まとめサイトや出典の無い記事だけを根拠にしない。
- 数字は出典に書いてあるものだけ使い、出典の日付も書く。

## 4 競合を見る

- YouTube の検索結果やチャンネルページで、伸びている動画の「切り口」（誰の、どんな悩みに、どう答えているか）と「型」（長さ・構成）を見る。
- **文章・台本・映像・サムネは写さない。** ボードには「自分ならどう変えるか」を必ず書く。
- ログインが要る画面や、自動で大量に読み込む操作はしない（YouTube の利用規約で自動収集が制限されているため）。
  自分のチャンネルの数字は、ご本人に YouTube Studio から CSV を書き出してもらう（yt-ops / weekly-report が読む）。

## 5 候補を書く

1つの候補に、次の5項目を必ず書く。

```
- 仮タイトル: 32字以内。数字か具体的な言葉を1つ
- 悩み: 誰の、どんな悩みに答えるか（1文）
- 骨組み: 3行（→ でつなぐ）
- 出典: URL（複数は「 / 」区切り）。見つからなければ「出典なし」
- 形: YouTube / ショート / note / SNS のどれか
```

最後に「おすすめの3つ」を、理由1行つきで書く。

## 6 点検

```
python3 $S/research_board.py check <ボードの絶対パス>
```

終了コード 0 になるまで直す。`注意` は目で見て判断する。

## 7 渡す

```
保存した場所   /絶対パス/research/YYYY-MM-DD_テーマ.md
おすすめ3つ    1 … / 2 … / 3 …
確かめきれなかったこと  （出典なしの候補など）
次の一歩       「候補◯で台本を書いて」と言ってください（yt-script）
```

## してはいけないこと

- 出典URLを作らない（見つからなければ「出典なし」）
- 他人の動画・記事の文章を写さない。タイトルをそのまま使わない
- ログインが必要なページの自動操作、大量の自動読み込み
- 「必ず伸びる」「確実に稼げる」などの言い切り
