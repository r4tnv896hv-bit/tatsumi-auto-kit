# 投稿の型（7種類）

どの型も「1投稿で1つのことだけ」。最後の1行で読む人が次にすること（保存・返信・プロフィールを見る）を1つだけ示す。

## 1 学び抜粋（リンクなし）
記事の無料部分の1見出しを、1つの気づきに縮める。

```
〇〇で毎回つまずいていた原因、【一言の原因】でした。

やったのは3つだけ。
1 【手順1】
2 【手順2】
3 【手順3】

【一言のまとめ】
```

## 2 問いかけ（リンクなし）
読者に答えてもらう。返信が来たら、その言葉を次の記事のネタ帳に書く。

```
〇〇をしている人に聞きたいです。
いちばん時間がかかっているのはどこですか？

A 【選択肢】
B 【選択肢】
C 【選択肢】

返信で教えてもらえたら、次の記事で答えます。
```

## 3 失敗談・体験（リンクなし）
ご本人の実際の体験だけを書く。無ければこの日は「学び抜粋」に差し替える。

```
【いつ】、〇〇で【失敗したこと】。
原因は【原因】でした。
いまは【変えたこと】にしています。
同じところで止まっている人の参考になれば。
```

## 4 一覧・まとめ（リンクなし）
保存されやすい形。

```
〇〇を始める前に決めておくこと5つ

1 【】
2 【】
3 【】
4 【】
5 【】

あとで見返す用に。
```

## 5 告知（リンクあり・週1回）
「何が手に入るか」を先に。値段の話は最後。

```
〇〇の手順を1本の記事にまとめました。

・【この記事で分かること1】
・【この記事で分かること2】
・【この記事で分かること3】

前半は無料で読めます。
【noteのURL】
```

## 6 振り返り＋LINE案内（リンクあり・週1回）

```
今週書いたことのまとめです。
・【月の投稿の要点】
・【水の投稿の要点】
・【土の投稿の要点】

LINE では【登録特典】をお渡ししています。
【LINEのURL】
```

## 7 引用・感想（任意・リンクなし）
読者の感想は「本人の許可を取った実物」だけ使う。作文しない。
