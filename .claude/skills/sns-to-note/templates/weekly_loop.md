# 週の振り返り（毎週日曜・15分）

## 1 数字を写す（5分）
plan.md の表に、各SNSと note のダッシュボードから数字を写す。測った日時も書く。

## 2 3つの割り算をする（5分）

| 割り算 | 意味 | 低いときに直す所 |
|---|---|---|
| プロフィールを見た人 ÷ 投稿の表示 | 投稿が「この人の他の話も見たい」と思わせたか | 投稿の1行目・型の配分 |
| note の閲覧 ÷ プロフィールを見た人 | プロフィールが記事に送れたか | プロフィール1行目・固定投稿 |
| 購入 ÷ note の閲覧 | 記事の無料部分が買う理由を作れたか | 題名・無料部分・有料ラインの位置 |

LINE 登録 ÷ note の閲覧 も同じように見る。

## 3 来週を決める（5分）
- いちばん反応が多かった型を、来週は1回増やす
- いちばん少なかった型を1回減らす（0にはしない）
- 直す所は1週間に1つだけ（同時に2つ変えると、どれが効いたか分からない）
- 決めたことを1行で記録する：「【日付】：〇〇を△△に変えた。理由：□□」
