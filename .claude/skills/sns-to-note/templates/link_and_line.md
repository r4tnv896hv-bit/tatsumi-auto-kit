# リンクの置き場所と LINE 登録の導線

## リンクの置き場所（3択。媒体の最新の仕様をご本人が確認して選ぶ）

| 置き場所 | よい所 | 気をつける所 |
|---|---|---|
| 本文の最後 | 迷わずクリックできる | 外部リンク付き投稿は表示が伸びにくいと言われることがある。毎回付けない |
| 自分の返信欄（ぶら下げ） | 本文は読み物として読まれる | 同じリンクを毎日ぶら下げると宣伝に見える。週2回まで |
| プロフィールのみ | 投稿がすっきりする | プロフィールの1行目で「何が手に入るか」を言い切っておく |

おすすめの初期設定：普段はプロフィールのみ、告知の日だけ本文の最後、LINE案内の日だけ返信欄。

## 固定投稿
- 告知の投稿を固定する。「前半無料」と「分かること3つ」が入っていること
- 2週間ごとに見直す

## LINE 登録の導線
1. 登録特典を1つ決める（例：記事内で使ったチェックリストの完全版、テンプレ1枚）
   - 有料記事の中身そのものは渡さない
2. note 記事の最後（有料部分の最後）にも LINE の案内を置く：買った人と次の接点を作るため
3. LINE の最初の自動メッセージ（あいさつ）に、特典の受け取り方と、次に届く内容を書く

あいさつ文の形：

```
登録ありがとうございます、【名前】です。
お約束の【登録特典】はこちらです：【特典のURL】

このLINEでは【頻度】に【届ける内容】をお送りします。
〇〇で困っていることがあれば、このトークにそのまま送ってください。
```

## プロフィールの形

```
【誰に】向けて、【何を】発信しています。
【実績：ご本人が埋める】
最新の記事（前半無料）と【登録特典】は下のリンクから。
```
