# sns-to-note（SNS → note 集客の下書きスキル）

**このスキルは下書きを作るだけです。投稿・予約投稿・いいね・フォロー・DM 送信は一切しません。**
投稿はご本人が、内容を読んでから手で行います。

---

## 全体の流れ

```
1 素材を受け取る   note 記事（Markdown）のパスと、媒体（X／Threads）、週の初日を聞く
2 予定表を作る     make_week_plan.py で7日分の型とネタを割り当てる
3 下書きを書く     templates/post_types.md の型で、1日1本ずつ書く（別案を1つずつ添える）
4 導線を決める     templates/link_and_line.md でリンクの置き場所と LINE の案内文を決める
5 点検する         check_posts.py が NG 0件になるまで直す
6 渡す             posts.md と「投稿前にご本人が確かめること」を渡す
7 週末の振り返り   plan.md の数字表をご本人に埋めてもらい、翌週の型の配分を決める
```

## 1 素材を受け取る

聞くこと（1回のメッセージでまとめて）：

- note 記事のファイル（なければ記事の題名と見出しを貼ってもらう）
- 主に使う媒体：X か Threads
- 週の初日（例：2026-11-09）
- プロフィールに何を置いているか（note／LINE／どちらも）

## 2 予定表を作る

```
python3 <スキルのフォルダ>/scripts/make_week_plan.py <記事.md> --start <YYYY-MM-DD> --out <出力フォルダ> --platform X
```

- 記事の「=== ここから有料 ===」より上の見出しだけがネタになる（有料部分の中身は SNS に出さない）。この目印は note-article が書くものと同じ。古い形「――――― ここから有料（有料ライン） ―――――」も読める
- 有料記事なのに目印が無いと、記事全体がネタになってしまう。実行したときに「除外した有料部分の見出し 0 個」と出たら、どこまで使ってよいかご本人に聞く
- リンクを付ける日は週2回（告知・LINE案内）だけ。残りの5日はリンク無しで「中身で役に立つ」投稿にする

## 3 下書きを書く

- `templates/post_types.md` の型を使う。型ごとの「書き出しの形」を守る
- 1投稿1メッセージ。X は重み付き280以内（日本語ならおよそ140字）
- 記事の文をそのまま貼らない。SNS 用に「1つの気づき」に縮める
- ご本人の実績・数字・お客様の声を作らない。必要な所は【】で空ける
- 同じ文の使い回しをしない（重複投稿は各SNSの規約・品質評価で不利）

## 4 導線を決める

`templates/link_and_line.md` を読んで、次の3つを決めて posts.md の先頭に書く：

- リンクの置き場所（本文末／自分の返信欄／プロフィールのみ）
- 固定投稿にする投稿
- LINE 登録の特典（登録した人に何を渡すか）と案内文

## 5 点検する

```
python3 <スキルのフォルダ>/scripts/check_posts.py <出力フォルダ>/posts.md
```

NG があれば直して再実行。終了コード 0 で次へ。

## 6 渡す

渡すときに必ず添える一覧：

- 【】の残り（URL・実績・特典名など）
- 投稿前にご本人が確かめること（事実・数字・言い過ぎ）
- 投稿は、ご本人が各SNSの画面から手で行うこと

## 7 週末の振り返り

plan.md の「週の終わりに記録する数字」をご本人に埋めてもらい、`templates/weekly_loop.md` の手順で翌週の配分を提案する。

---

## してはいけないこと

- 投稿・予約・自動いいね・自動フォロー・一斉DM、そのためのスクリプトを書くこと
- 他人の投稿の書き写し、ステマ（宣伝と分からない宣伝）
- 「誰でも」「必ず」稼げる、という言い切り
- 有料部分の中身をそのまま SNS に出すこと
