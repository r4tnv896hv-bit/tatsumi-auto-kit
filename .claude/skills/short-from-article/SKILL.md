# short-from-article（記事 → ショート動画）

ご本人が書いた記事から、文字スライドのショート動画を作るスキルです。
投稿・アップロード・送信は一切しません。できあがるのはパソコンの中のファイルだけです。

使う人はエンジニアではない方です。専門用語を使わず、短い文で話しかけてください。

---

## 最初に確かめること（ここで止まる）

```
1 記事はご本人が書いたものですか？（他人の記事を動画にするのは、許可がない限りやりません）
2 記事の場所（.md / .txt のファイル、または文章をそのまま貼ってもらう）
3 動画の最後に見てほしい行動（例: プロフィールのリンク・記事を読む・フォロー）
4 声: say（無料・回数制限なし。Linux では `--tts say` で Open JTalk が読む）か Gemini（自然・無料枠は1日の回数が少ない）か
```

---

## 全体の流れ

```
1 記事を読む          大事な主張・数字・具体例を抜き出す
2 台本3本             scripts.json を書く（templates/scripts_template.json の形）
3 台本の点検          scripts/check_scripts.py
4 ご本人のOK          3本の台本を見せ、作る1本（または3本）を選んでもらう
5 動画にする＋点検    scripts/render_short.py
6 渡す
```

以下 `$S` は、このファイルと同じフォルダの `scripts/` の絶対パスです。

### 2 台本の書き方（Claude がやること）

1本 = 5場面。全体で 20〜45秒くらいが目安です。

```
hook    最初の2秒で言い切る一言。問いかけ・意外な結論・「やってはいけない」など
        読み上げ 16文字以内が目安
point1  ポイント1（1場面1つのことだけ）
point2  ポイント2
point3  ポイント3
cta     見た人にしてほしい行動を1つだけ
```

各場面に書くもの。

```
slide      画面の真ん中の大きな文字。1行8文字・2行まで。改行は \n で自分で入れるときれい
narration  読み上げる文。数字や読み間違えそうな言葉は、ひらがなで書く（3か月→さんかげつ）
           「元気に読んで」などの指示は書かない（そのまま読み上げられる）
caption    字幕に出す文（省略すると narration をそのまま出す）
           narration をひらがなにした所は、ここに漢字・数字で書く
```

3本は、切り口を変えます（例: 全体の手順／つまずきやすい所／気持ちの面）。
記事に書いていないことは足しません。数字・固有名詞は `fact_check` に「記事のどこに書いてあるか」を書きます。

### 3 台本の点検

```bash
python3 $S/check_scripts.py /絶対パス/scripts.json
echo $?
```

0 なら合格。★の行を直してから進みます。

### 5 動画にする＋点検

```bash
# say で作る（無料）
python3 $S/render_short.py /絶対パス/scripts.json --index 1 --tts say --outdir /絶対パス/出力フォルダ
echo $?

# Gemini で作る（キーを ~/.zshrc に入れている場合）
zsh -ic 'python3 '"$S"'/render_short.py /絶対パス/scripts.json --index 1 --tts gemini --outdir /絶対パス/出力フォルダ'
```

- `--index` は何本目か（1〜3）
- Gemini は1場面＝1回の呼び出し（1本で5回）。無料枠は1日の回数が少ないので、試し打ちを何度もしない
- Gemini が途中で失敗したら、声が混ざらないよう全場面を say で作り直します（画面に出ます）
- **キーは画面に出さない・ファイルに書かない・人に送らない**

1本ずつ、次を自動でやります。

```
読み上げ   場面ごとに音声を作り、その長さ＋0.45秒 を場面の長さにする（30fpsのコマ数ちょうど）
スライド   1080x1920 の画像（見出し・進み具合の点・大きな文字・POINTの印）
字幕       読み上げの文を、下 420px を空けて焼き付け（.srt も一緒に書き出す）
つなぐ     場面を concat demuxer で無劣化につなぐ
情報消し   作成日時・エンコーダ名・x264 の署名などを消す
点検       全体・映像・音声 の3つの長さが、場面の合計と ±0.5秒 以内か／1080x1920か／情報が残っていないか
```

終了コード 0 なら合格。3 なら `_NG.mp4` になり、渡しません。

### 6 渡す

```
- 動画と .srt の絶対パス、長さ（点検の数字と、測った時刻）
- 使った声（say / Gemini）
- ご本人に確かめてほしいこと:
   読み間違い（特に数字・固有名詞）／字幕の誤字／記事と言っていることがずれていないか
- Gemini の声を使ったときは、AIの声であることを、投稿先のルールに沿って表示するか確かめてもらう
```

---

## うまくいかないとき

```
say の声が英語になる        → システム設定 > アクセシビリティ > 読み上げコンテンツ で Kyoko を入れる
GEMINI_API_KEY が読めない    → zsh -ic '…' で動かしているか確認。無理なら --tts say
Gemini が 429 / 503          → 混雑か回数切れ。時間をおくか say で作る
文字がはみ出す               → slide を短くするか \n で区切る（1行8文字まで）
```
