# weekly-report（週報のスキル）

1週間に作ったものと、数字と、タスクを1枚にまとめます。
**数字は、ご本人が渡した CSV にあるものだけ。** 推測で数字を書きません。どこにも送りません。

以下 `$S` はこのファイルと同じフォルダの `scripts/`、`$W` は作業フォルダ（CLAUDE.md の絶対パス。初期値 `~/kit-work`）です。

---

## 流れ

```
1 材料を集める   CSV があるか聞く（無くても作れる）
2 週報を作る     weekly_report.py
3 提案を書く     週報を読み、来週やることを最大3つ
4 渡す           3行で要点 → ファイルの場所
```

## 1 材料を集める（1回のメッセージでまとめて聞く）

```
週報を作ります。次のファイルがあれば場所を教えてください（無くても作れます）。
  1 YouTube Studio の「表データ.csv」
    （アナリティクス → 詳細 → 期間を「過去7日間」→ 右上の書き出し → カンマ区切り値）
  2 SNS の数字表（sns-post の metrics_template.csv の形）
  3 秘書のデータフォルダ（secretary を使っている場合）
```

## 2 週報を作る

```
python3 $S/weekly_report.py --work $W [--yt-csv <表データ.csv>] [--sns-csv <metrics.csv>] [--tasks <秘書のフォルダ>]
```

## 3 提案を書く

できたファイルを読み、「5 来週の提案」の【】を最大3つ埋める。書き方：

```
1. 【何を】【どれだけ】する（理由：週報の◯番の、どの数字・どの事実から）
```

- 理由には、週報に書いてある事実だけを使う。週報に無い数字を足さない
- 作ったものが0件の置き場があれば、それを1つめの提案にしてよい（例：「SNS の下書きが0件 → 動画1本から sns-post で5本」）
- 動画が5本未満・投稿が5本未満のときは「数が少ないので参考程度」と添える

## 4 渡す

```
今週の要点（3行）
  作ったもの：YouTube ◯ / ショート ◯ / note ◯ / SNS ◯
  数字：（CSV があれば一番伸びたもの1つ）
  タスク：期限切れ ◯件
保存した場所：/絶対パス/reports/YYYY-MM-DD_weekly.md
決めてほしいこと：提案1〜3のどれをやるか
```

決まったら、`$W/memory/` に「日付・決めたこと・理由」を1件1ファイルで書き、`MEMORY.md` に1行足す。

## 定期実行にしたいとき

毎週決まった時刻に作りたい場合は、`scripts/` フォルダの `weekly_cron_example.txt` をご本人に見せ、設定はご本人に行ってもらう。
- パスは必ず絶対パス（定期実行はホームのフォルダで動くため）
- パソコンが閉じている・スリープ中は動かない

## してはいけないこと

- 数字を作る・盛る・丸めて別の数字にする
- 週報をメール・チャット・SNS に送る
- タスクを勝手に完了にする
