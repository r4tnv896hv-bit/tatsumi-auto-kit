# 編集指示書（1本ぶん）

> AI エージェントにも、人の編集者にも、同じこの紙を渡します。空欄を埋めてから渡してください。

## 1 基本

| 項目 | 記入 |
|---|---|
| 動画の仮タイトル | 【タイトル】 |
| 見てほしい人 | 【誰に】 |
| 向き・サイズ | 横 1920x1080 ／ 縦 1080x1920 |
| 仕上がりの長さ | 【〇分〇秒前後】（許容 ±【〇】秒） |
| 締め切り | 【日付・時刻】 |
| 素材フォルダ | 【絶対パス】 |

## 2 素材の一覧（vedit.py probe の結果を貼る）

| ファイル | 長さ(秒) | 解像度 | 音 | 使い方 |
|---|---|---|---|---|
| | | | | メイン／差し込み／使わない |

## 3 カットの方針

- [ ] 無音（0.6秒以上）は詰める（silence で下書き → 人が確認）
- [ ] 言い間違い・言い直しは、言い直した後を残す
- [ ] 冒頭は【〇秒】から始める（あいさつは切る／残す）
- [ ] 残したい場面：【〇分〇秒〜〇分〇秒：理由】
- [ ] 必ず切る場面：【個人情報・画面に映った通知・他人の名前など】

## 4 字幕

- 方式：クリップごとの短い字幕（caption）／全文字幕（.srt を焼き込み）／字幕なし
- 表記ルール：【数字は半角、「AI」は大文字、など】
- 固有名詞の正しい表記：【一覧】

## 5 BGM・音

| 項目 | 記入 |
|---|---|
| BGM ファイル | 【パス】（利用条件を確認済み：はい／いいえ） |
| 音量 | 0.10〜0.15（声より必ず小さく） |
| 最後のフェードアウト | 2 秒 |
| 音量そろえ（loudnorm） | する |

## 6 書き出し後に必ず見ること

- [ ] edit_report.md の判定が OK（予定と実物の長さの差が 0.3 秒以内）
- [ ] 冒頭3秒・つなぎ目・最後の5秒を目で見た
- [ ] 字幕の誤字・固有名詞
- [ ] BGM が声に勝っていない
- [ ] 他人の素材・音楽・顔・個人情報が入っていない
- [ ] メタデータを消した版である（vedit.py は自動で消す）

## 7 戻し方（修正の頼み方）

```
【〇分〇秒】の【何が】【どうなっている】ので、【どうしてほしい】。
例：0分12秒のつなぎ目で声が途中で切れているので、out を 0.3 秒後ろにしてほしい。
```
