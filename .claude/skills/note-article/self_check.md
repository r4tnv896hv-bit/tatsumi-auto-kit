# 自己チェック表（目視）

check_draft.py の機械の検査のあと、1つずつ目で見ます。
結果は「OK／直した／要確認」のどれかで、work_memo.md に書きます。

---

## A. 事実と数字

- [ ] 確かめられない数字が、確かな事実のように書かれていない
- [ ] 料金・手数料・規約・税金・法律の話には【要確認】が付いている
- [ ] 使う人の体験・実績・数字は、聞き取りで聞いたものだけ
- [ ] 「〇割の人が」「多くの人が」など、根拠の無い割合・多数の言い方が無い

## B. 約束とあおり

- [ ] 収入の金額を約束していない（本文・題名・販売文のすべて）
- [ ] 必ず／確実に／誰でも／保証／最短 を使っていない
- [ ] 期限で急かす・不安を大きくする言い方が無い
- [ ] 「向いていない人」を販売文に書いている

## C. 写していないか

- [ ] 他の人の記事・本・動画の文章を写していない
- [ ] 言い回しをほぼそのまま借りた所が無い（借りたのは考え方だけ）
- [ ] 他の人の図・画像を使う指示になっていない

## D. 出どころの置き場所

- [ ] 本文・図の説明に「出典：」「参考：」「〜によると」が無い
- [ ] 本文にURLが無い（入れる場合は、使う人が指定したものだけ）
- [ ] 出どころは work_memo.md に書いてある

## E. 読みやすさ

- [ ] 1行20〜25字くらい、1段落3行まで
- [ ] 表を使っていない
- [ ] 太字は1つの大見出しに1〜2か所まで
- [ ] 「いかがでしたか」「〜でしょう」「〜と言えます」で締めていない
- [ ] 専門用語は最初に1回、言い換えている

## F. 中身と約束の一致

- [ ] 題名の数字と、本文で数えた項目の数が同じ
- [ ] 販売文の「この先で分かること」が、有料部分の見出しと同じ
- [ ] 図の指示が4〜7枚あり、どれも「図の題」と「図の説明」がある
- [ ] 空白を除いて 7,000〜9,000字

## G. 渡す前

- [ ] 【要確認】の数と、work_memo.md の要確認一覧の数が同じ
- [ ] 「事実はご自身で確かめてください」の一文を、使う人に伝えた
- [ ] 公開・投稿・送信をしていない
