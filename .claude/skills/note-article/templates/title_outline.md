# 題名5案と構成の出し方

---

## 題名5案（この形で出す）

```
題名の案です。番号で1つ選んでください（混ぜる・直すもOKです）。

1. 〇〇〇〇｜△△△△が分かる5つの手順
   ねらい：（なぜこの言い方か、1行）

2. ……
   ねらい：……

（5まで）
```

出す前の確認：

- [ ] 5案すべてに数字がある
- [ ] 数字は「手順の数・項目の数・時間」など数えられるもの
- [ ] 収入の金額・「稼げる」の約束が無い
- [ ] 飾りの言葉（必見・今すぐ・衝撃・完全保存版）が無い
- [ ] 5案の切り口が全部ちがう（手順型／失敗型／時間型／比べる型／チェック型 など）

切り口の例：

- 手順型：「〇〇を始める5つの手順」
- 失敗型：「〇〇で最初につまずく7つの所と避け方」
- 時間型：「平日30分で〇〇する方法」
- チェック型：「公開前に見る10の点検項目」
- 質問型：「〇〇でよく聞かれる6つの質問への答え」

---

## 構成（この形で出す）

```
題名：（選ばれた題名）
読者：（1行）
ゴール：（1行）
全体の字数：約8,000字（空白を除く）
有料ライン：（H2の何番目の前か／無料記事なら「なし」）

はじめに（約500字）
  ここで分かること：……

## H2-1 〇〇〇〇（約1,200字）
  ここで分かること：……
  ### H3 ……
  ### H3 ……
  ［図1］図の題：……

## H2-2 ……
……

（有料ライン・販売文）

## H2-x ……

まとめ（約400字）
  今日やる1つのこと：……
```

出す前の確認：

- [ ] H2が5〜7個
- [ ] 各H2の目安字数の合計が7,000〜9,000字
- [ ] 図が4〜7枚、それぞれ置く場所が決まっている
- [ ] 題名の数字と、本文で数える項目の数が合っている
- [ ] 有料記事なら、有料ラインより前だけで「読んでよかった」と思える
