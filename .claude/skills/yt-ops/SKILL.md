# yt-ops（YouTube 運用エージェントのスキル）

チャンネル1つを「チャンネルフォルダ」1つで管理します。中身はすべてふつうのファイル（CSV と Markdown）です。
このスキルは段取りと記録だけを行います。**YouTube への投稿・予約公開・コメント返信・送信はしません。**

スクリプトは `<このスキルのフォルダ>/scripts/ops.py`（以下 `OPS`）。Python 3.8 以上だけで動きます。
チャンネルフォルダは必ず絶対パスで扱います（例 `/Users/<名前>/yt-ops/<チャンネル英名>`）。

---

## 最初に1回（チャンネルフォルダを作る）

1. ご本人に4つ聞く：チャンネル名／誰に向けたチャンネルか／発信の柱を3つ／公開する曜日（週1〜2本をすすめる）
2. 作る
   ```
   python3 OPS init --dir <フォルダ> --name "<チャンネル名>" --days 火,金 --pillars "柱1,柱2,柱3" --audience "<誰に>"
   ```
3. `templates/CLAUDE_ops.md` を `<フォルダ>/CLAUDE.md` にコピーし、【】をご本人と埋める
4. ネタを10個 add する（ご本人の体験から出たネタを優先）

## 週のまわし方（ルーティン）

| いつ | やること | コマンド |
|---|---|---|
| 月曜の朝 | 週の段取り表を作り、遅れ・空き枠・今週の締め切りを伝える | `week --dir <フォルダ>` |
| 作業が進むたび | 段階を進める | `move --id V003 --stage script` |
| 公開の前日 | アップロード前チェック表を作り、ご本人に渡す | `checklist --id V003` |
| 公開したら | 公開済みにする（アップロードはご本人） | `move --id V003 --stage published` |
| 金曜 | Studio の CSV をもらい、振り返りを作る | `review --csv <表データ.csv>` |
| いつでも | 一覧 | `list --dir <フォルダ>` |

段階（stage）: `idea`ネタ → `plan`企画OK → `script`台本OK → `record`収録済み → `edit`編集済み → `thumb`サムネOK → `ready`公開準備OK → `published`公開済み

締め切りは公開日から逆算します：企画 9日前／台本 6日前／収録 4日前／編集・サムネ 2日前／最終確認 1日前。

## 伝え方のルール

- 段取り表を作ったら、全文を貼らずに3行で伝える：「遅れ〇件（いちばん古いもの）」「今週の締め切り〇件」「空き枠〇つ（候補〇〇）」
- 空き枠をうめる動画は**ご本人が決める**。候補を2〜3個出して番号で選んでもらう
- 決まったことは `<フォルダ>/decisions.md` に「日付・決めたこと・理由・見直す日」で1行書く
- 数字を伝えるときは、測った時刻を添える（review のファイルに自動で入る）

## 数字の振り返り（review）

ご本人に CSV を書き出してもらいます：
YouTube Studio → アナリティクス → 右上「詳細」→ 期間を「過去28日間」→ 右上の下向き矢印（書き出し）→「カンマ区切り値（.csv）」→ zip を開いて `表データ.csv`。

判定は中央値との比較（±20%）です。

| 判定 | 意味 | 次の一手 |
|---|---|---|
| 当たり | クリック率も再生率も高い | 「なぜ」を1行で書き、同じ理由で1本企画 |
| 入口は強い | クリック率だけ高い | タイトル・サムネの型を残し、中身の冒頭を強化 |
| 中身は強い | 再生率だけ高い | タイトル・サムネを作り直す案を2つ |
| 入口が弱い | クリック率が低い | タイトル・サムネの差し替え案 |
| 途中で離脱 | 再生率が低い | 冒頭15秒で結論を言う構成に |
| 要見直し | 両方低い | 企画（誰の悩みか）から見直す |

本数が5本未満のときは「参考程度」と必ず添えます。

## やってはいけないこと

- YouTube への自動アップロード・予約・コメントの自動投稿（規約と事故の両面で、人が行う）
- ご本人が決めていない公開日や企画を、勝手に queue に入れる
- 数字を作る・盛る（review は CSV の数字だけを使う）
- 鍵やパスワードをチャンネルフォルダに書く

## つまずいたとき

| 症状 | 対処 |
|---|---|
| `channel.json が無い` | `--dir` のパスがちがう。絶対パスで指定する |
| `列が読めません` | 「表データ.csv」以外（グラフデータ.csv など）を渡している |
| 決まった時刻に自動で動かない | パソコンがスリープ／閉じている。または相対パスで書いている |
