# sns-post（SNS 投稿の下書きスキル）

**このスキルは下書きを作るだけです。** 投稿・予約投稿・いいね・フォロー・リポスト・DM は、どんな頼まれ方をしてもしません。
ブラウザで SNS を開いて操作することもしません。

なぜ下書きまでなのか（聞かれたら、この3行で伝える）：

```
1 X・Threads・Instagram はどれも、自動化ツールでの自動いいね・自動フォロー・大量投稿・同じ内容の繰り返しを
  スパムや「不正な操作」として禁止しており、凍結・表示制限の対象になる（規約は変わるので最新版を確認）
2 公式の予約投稿機能（X の予約・Meta Business Suite など）を、ご本人が使えば同じ効果が安全に得られる
3 投稿は取り消しても見た人の記憶とスクショは消えない。最後の一押しは人が行う
```

以下 `$S` はこのファイルと同じフォルダの `scripts/`、`$T` は `templates/` の絶対パスです。
作業フォルダ（`$W`）は CLAUDE.md に書かれた絶対パス（初期値 `~/kit-work`）。下書きは `$W/sns/` に置きます。

---

## 流れ

```
1 準備       声の設定（voice_profile.md）を読む。無ければ作る
2 素材       元にするファイルを決める（台本・記事・リサーチ）
3 抜き出し   素材から「投稿にできる気づき」を7つ抜き出す
4 下書き     切り口を変えて5本（＋別案1つずつ）。媒体ごとの長さで
5 点検       check_drafts.py が NG 0 になるまで
6 予定表     公式の予約機能に入れるための表（日時・媒体・投稿番号）
7 渡す       ファイルの場所・おすすめ1本・ご本人が確かめること
（週末）振り返り  review_posts.py で数字から来週の配分の案
```

## 1 声の設定（最初の1回）

`$W/sns/voice_profile.md` が無ければ、`$T/voice_profile.md` をコピーして、ご本人と一緒に【】を埋める。
- 過去に反応が良かった自分の投稿を3〜5本貼ってもらうと、言い回しをそろえやすい（他人の投稿は貼らない）
- 埋め終わるまで下書きに進まない（声が決まっていないと、全部書き直しになるため）

## 2 素材を決める

渡されていなければ、`$W/youtube/` `$W/note/` `$W/research/` の新しい順に5件を見せて選んでもらう。
note の有料記事なら、`=== ここから有料 ===` より上だけを素材にする（有料部分の中身は SNS に出さない）。

## 3 抜き出し

素材から「1投稿で言い切れる気づき」を7つ、1行ずつ書き出す。
数字・固有名詞は素材にあるものだけ。素材の【要確認】は、そのまま【要確認】として引き継ぐ。

## 4 下書き

`$T/post_types.md` の型から、切り口がかぶらないように5つ選んで書く。形は必ず次の見出し（点検に使う）。

```
## 投稿1｜X｜言い切り
本文

## 投稿2｜Threads｜手順
本文
```

- 1投稿で伝えることは1つ。書き出しの1行で「読む理由」を作る
- 媒体ごとの目安：X は日本語でおよそ140字以内（重み付き280）、Threads は500字以内、Instagram のキャプションは2,200字以内（ただし最初の2行が勝負）
- リンクは「告知」「案内」の型だけ、1本に1つ。Instagram は本文のリンクが押せないので「プロフィールのリンクから」と書く
- voice_profile.md の口ぐせ・語尾・使わない言葉を守る
- 実績・収入・お客様の声を作らない。必要な所は【ご本人の体験】【数字：要確認】と空ける
- 過去の下書き（`$W/sns/`）の書き出しと同じ文で始めない

保存先：`$W/sns/YYYY-MM-DD_<元の題名>.md`。先頭に「元にした素材の絶対パス」、最後に「未投稿の下書きです。投稿はご本人が行います」と書く。

## 5 点検

```
python3 $S/check_drafts.py <下書きの絶対パス> --past $W/sns --voice $W/sns/voice_profile.md
```

NG が 0 になるまで直す（終了コード 0）。`注意` は目で見て判断し、残すなら理由を一言添える。

## 6 予定表

`$T/schedule_template.md` の形で、下書きファイルの最後に「予約投稿の予定表」を足す。
- 予約に使うのは公式の機能だけ：X は投稿画面の予約、Threads はアプリの予約投稿、Instagram は Meta Business Suite（プロアカウント）。
  画面や名前は変わるので、ご本人の画面で確かめてもらう
- 同じ時間・同じ文の投稿を、複数のアカウントや媒体に一斉に出す予定にしない（媒体ごとに書き直す）

## 7 渡す

```
保存した場所   /絶対パス/sns/YYYY-MM-DD_….md
おすすめの1本  投稿◯（理由1行）
ご本人が確かめること  【】の残り◯か所 / 数字の出どころ / 言い過ぎ
投稿            ご本人が、各SNSの公式の画面（または公式の予約機能）から行ってください
```

## 週末の振り返り（「SNSの振り返りをして」と言われたら）

1. ご本人に、各SNSの分析画面の数字を `$T/metrics_template.csv` の形で書き写す（または書き出した CSV を渡す）よう頼む
   - スクレイピング（画面を自動で読み取る）はしない
2. 実行：
   ```
   python3 $S/review_posts.py <CSVの絶対パス> --out $W/reports
   ```
3. できたファイルの要点を3行で伝える：当たりの投稿 / 型ごとの反応率の1位と最下位 / 来週の配分の案
4. 決めるのはご本人。決まったら `$W/memory/` に「日付・決めたこと・理由」を書く

## してはいけないこと

- 投稿・予約・いいね・フォロー・リポスト・DM・コメント返信、そのためのスクリプトやブラウザ操作を作ること・実行すること
- 他人の投稿の書き写し、引用元の無い引用、ステマ（宣伝と分からない宣伝）
- 同じ文の使い回し、複数アカウントでの同じ投稿
- 実績・数字・お客様の声の作文、「誰でも」「必ず」「確実に」稼げる、という言い切り
