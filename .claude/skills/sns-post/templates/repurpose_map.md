# 1つの素材 → 1週間分の投稿（使い回しの地図）

元の素材1本から、媒体ごとに「書き直した」投稿を作ります。同じ文のコピーは作りません。

| 元の素材 | 抜き出すもの | X | Threads | Instagram |
|---|---|---|---|---|
| YouTube 台本 | 冒頭15秒の悩み | 言い切り | 問いかけ | ― |
| YouTube 台本 | 本編の見出し3つ | 手順 | 手順（少し長め） | 一覧・保存用 |
| YouTube 台本 | factcheck の数字（確認済みのものだけ） | 比べる | ― | 一覧・保存用 |
| note 記事（無料部分） | 見出し1つ | よくある間違い | 言い切り | ― |
| note 記事（無料部分） | まとめ3行 | 振り返り＋案内 | 振り返り＋案内 | 告知 |
| 作業の記録 | 工夫したこと | 制作の裏側 | 制作の裏側 | ― |

1週間の例（1日1本、リンクは2本まで）：

```
月 X 言い切り          火 Threads 問いかけ     水 X 手順
木 Instagram 一覧      金 X 告知（リンク）      土 Threads 制作の裏側
日 X/Threads 振り返り＋案内（リンク）
```
