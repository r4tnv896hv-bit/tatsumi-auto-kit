# 投稿の型（10種類）

どの型も「1投稿で1つのことだけ」。書き出しの1行で読む理由を作り、最後の1行で次の行動を1つだけ示します。
【】は素材かご本人の情報で埋めます。素材に無いことは書きません。

| 番号 | 型 | リンク | 向いている媒体 |
|---|---|---|---|
| 1 | 言い切り | なし | X / Threads |
| 2 | 手順 | なし | X / Threads / Instagram |
| 3 | よくある間違い | なし | X / Threads |
| 4 | 比べる | なし | X / Instagram |
| 5 | 問いかけ | なし | Threads / X |
| 6 | 一覧・保存用 | なし | Instagram / X |
| 7 | 体験・失敗談 | なし | すべて（ご本人の体験だけ） |
| 8 | 制作の裏側 | なし | Threads / X |
| 9 | 告知 | あり（週1） | すべて |
| 10 | 振り返り＋案内 | あり（週1） | X / Threads |

## 1 言い切り
```
【結論を1行で言い切る】

理由は【理由を一言】。
【具体例を1〜2行】

【もう一度、短く結論】
```

## 2 手順
```
【何か】をするなら、この3つの順番です。

1 【手順1】
2 【手順2】
3 【手順3】

1だけでも今日できます。
```

## 3 よくある間違い
```
【〇〇】だと思っている人が多いのですが、実は【△△】です。

【なぜそう言えるか、1〜2行】

【では何をすればいいか、1行】
```

## 4 比べる
```
【A】と【B】、どちらがいいか。

A：【特徴】
B：【特徴】

【こういう人はA、こういう人はB】
```

## 5 問いかけ
```
【〇〇】をしている人に聞きたいです。
いちばん時間がかかっているのはどこですか？

A 【】
B 【】
C 【】

返信で教えてもらえたら、次の動画で答えます。
```

## 6 一覧・保存用（Instagram はカルーセルの1枚目の文にも使える）
```
【〇〇】の前に決めておくこと5つ

1 【】
2 【】
3 【】
4 【】
5 【】

あとで見返す用に保存しておいてください。
```

## 7 体験・失敗談（ご本人の体験が無い日は使わない）
```
【いつ】、【何で失敗したか】。
原因は【原因】でした。
いまは【変えたこと】にしています。
```

## 8 制作の裏側
```
今週の動画（記事）は、【作るときに工夫したこと】をしました。

【工夫の中身を2〜3行】

【次に試すこと】
```

## 9 告知（リンクあり・週1回まで）
```
【何が手に入るか】を1本にまとめました。

・【分かること1】
・【分かること2】
・【分かること3】

【URL】（Instagram は「プロフィールのリンクから」）
```

## 10 振り返り＋案内（リンクあり・週1回まで）
```
今週のまとめです。
・【要点1】
・【要点2】
・【要点3】

くわしくは【YouTube / note】で。
【URL】
```
