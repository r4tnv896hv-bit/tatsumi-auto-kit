# アカウントの声（voice_profile.md）

> sns-post が毎回読みます。【】を埋めてください。1アカウントにつき1ファイル。
> 複数のアカウントがある場合は voice_profile_<アカウント名>.md に分け、頼むときに「◯◯の声で」と言います。

## アカウント
- 名前・ID：【例：ゆる家計ラボ @example】
- 媒体：【X / Threads / Instagram】
- 立ち位置（一言）：【例：手取り20万円台の一人暮らしが、我慢しない節約を試す記録】
- 読む人：【例：社会人1〜3年目。お金の話は苦手だが、損はしたくない】
- 読んだあとにしてほしいこと：【例：保存する / プロフィールから YouTube を見る】

## 話し方
- 一人称：【私 / 僕 / 筆者は使わない】
- 語尾：【です・ます / 言い切り（〜だ・〜する）/ 混ぜない】
- 1文の長さ：【例：30字以内】
- 口ぐせ（使ってよい言い回し）：【例：結論から / やることは3つだけ】
- 使わない言葉：【例：絶対、神、ヤバい、誰でも】
- 絵文字：【使わない / 1投稿1個まで】
- ハッシュタグ：【使わない / 1〜2個 / Instagram だけ5個まで】

## 扱う話題
- 柱1：【】
- 柱2：【】
- 柱3：【】
- 扱わない話題：【例：政治、特定の人の批判、投資の個別銘柄】
