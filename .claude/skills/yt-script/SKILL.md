# yt-script（顔出しなしYouTubeの台本スキル）

顔を出さない解説動画の「台本」を作ります。
公開・投稿・送信はしません。できあがるのはパソコンの中のファイルだけです。

使う人はエンジニアではない初心者です。専門用語を使わず、短い文で話しかけてください。

---

## 全体の流れ（この順で、1段ずつ進める）

```
1 聞き取り      チャンネル名・テーマ・見てほしい人・動画の長さを聞く
2 視聴者を決める  「誰の、どんな悩みを、見終わったらどうなるか」を3行にまとめ、OKをもらう
3 タイトル3案    3つ出して1つ選んでもらう
4 台本          場面（シーン）ごとに「ナレーション」と「画面に出すもの」を書く
5 機械チェック   check_script.py で長さ・抜け・言ってはいけない言い方を点検
6 ファクトチェック表  数字・制度・固有名詞を一覧にして、ご本人に確かめてもらう
7 渡す          ファイルの場所と「ご自身で確かめること」を伝える
```

各段で答えをもらうまで、次の段に進まないでください。
ただし、ご本人が「おまかせ」と言ったら、こちらで決めて先に進んでかまいません（決めた内容は必ず書いて見せる）。

---

## 作業フォルダ

最初に、作業フォルダを1つ作ります。パスは**絶対パス**で扱ってください。

```
<作業フォルダ>/youtube/<日付>_<短い英数字名>/
  hearing.md      聞き取りメモ
  script.json     台本（次のスキル yt-narration と yt-video がこれを読む）
  script.md       人が読む用の台本（script.json から作る）
  factcheck.md    ファクトチェック表
```

例: `/Users/あなた/kit-work/youtube/20261102_koteihi/`
作業フォルダは CLAUDE.md の「フォルダの地図」に書かれた絶対パス（初期値 `~/kit-work`）。書かれていなければ、いまの作業場所に `yt_projects/` を作る。

---

## 1 聞き取り

`templates/hearing.md` の質問を、上から順に聞きます。一度に全部聞かず、2〜3問ずつ。

## 2 視聴者を決める

次の3行にまとめて見せ、OKをもらいます。

```
誰が     例）手取り20万円台で、毎月なんとなくお金が残らない一人暮らしの会社員
悩み     例）節約したいが、食費を削るのはつらい
見たあと  例）今日、スマホ代と保険の見直しを1つ始められる
```

## 3 タイトル3案

- 3案とも、数字か具体的な言葉を入れる（「3つの順番」「月5,000円」など）
- 32文字以内を目安
- 大げさな言い方・うそになる言い方はしない（「誰でも」「絶対」「確実に稼げる」など）
- 3案は「切り口」を変える（例: 結論先出し型／失敗回避型／手順型）

## 4 台本（script.json）

`templates/script_template.json` をコピーして埋めます。形は次のとおりです。

```json
{
  "channel": "チャンネル名",
  "title": "選んだタイトル",
  "target_minutes": 9,
  "voice_note": "落ち着いた、ゆっくりめの声",
  "scenes": [
    {
      "id": "s01",
      "narration": "字幕に出す文（読みやすい表記。数字は 3つ でよい）",
      "yomi": "読み上げ用の文（任意。数字や英字をひらがなに：みっつ、えーあい）",
      "visual": {
        "type": "text",
        "heading": "画面の大きな文字（15文字以内）",
        "body": "画面の小さな文字（任意・30文字以内）"
      }
    }
  ]
}
```

- `visual.type` は `"text"`（文字のスライド）か `"image"`（自分で用意した画像）。
  画像のときは `"image": "/絶対パス/画像.png"` と書き、`heading` も入れておく（画像が無いときの予備）。
  **画像は自分で撮った・作った・使ってよいと確認できたものだけ。** ネットで拾った画像は使わない。
- `yomi` は省略可。省略したら `narration` を読み上げる。
  数字・英字・記号は読み間違えやすいので、`yomi` にひらがなで書くのがおすすめ。
- 1シーンは 15〜40秒（ナレーション約 80〜200文字）。
- 8〜10分の動画なら、シーン 18〜30個、ナレーション合計 約2,600〜3,400文字（1分あたり約330文字）。

### 台本の組み立て（8〜10分のとき）

```
s01      つかみ（15秒）     視聴者の悩みを1文で言い当てる＋この動画で分かることを言う
s02      結論の予告（20秒）  結論を先に言う（最後まで引っぱらない）
s03-     本題（7〜8分）     ポイントごとに「理由 → 具体例 → 今日やること」
最後から2  まとめ（30秒）     ポイントを箇条書きで振り返る
最後      お願い（15秒）     チャンネル登録・コメントのお願いは1回だけ、短く
```

### オリジナルの価値を必ず入れる（大事）

YouTube は「大量生産・使い回し」の動画を収益化しません。台本に、次のどれかを最低2つ入れてください。

- ご本人の体験・失敗・実際の数字（ご本人に聞く。作らない）
- 自分で作った比較表・計算例・手順
- 視聴者の質問への回答

ご本人の体験が分からない所は `【ここにご自身の体験：例）〇〇】` と書いて残し、作り話で埋めないでください。

### 台本の書き方

- 1文は40文字以内。耳で聞いて分かる言葉。
- 「〜でしょう」「〜と言われています」でぼかさない。言い切れないことは言わない。
- 数字・制度・料金は、必ずファクトチェック表に載せる。
- 他人の動画・本・記事の文章を写さない。要約するときも自分の言葉で。

## 5 機械チェック

```
python3 <このスキルのフォルダ>/scripts/check_script.py <作業フォルダ>/script.json
```

（Windows は `python3` を `python` に読み替え）

- `NG` が出たら直して、もう一度実行。終了コード0になるまで。
- 短い試し動画（30〜60秒）を作るときは `--target-sec 45` をつける。
- 実行すると `script.md`（人が読む用）も同じフォルダに作られます。

## 6 ファクトチェック表（factcheck.md）

`templates/factcheck.md` を使い、台本に出てくる次のものを全部書き出します。

- 数字（金額・割合・期間・件数）
- 制度・法律・料金プランの説明
- 会社名・サービス名・人名

それぞれ「どこで確かめるか（公式サイト名など）」を書き、**確かめるのはご本人**だと伝えてください。
こちらで「確認済み」と書かないこと。

## 7 渡す

次の形で伝えます。

```
できたもの
  台本        /絶対パス/script.json（人が読む用: script.md）
  確認表      /絶対パス/factcheck.md
ご自身で確かめること
  ・factcheck.md の項目（N個）
  ・【ここにご自身の体験】の穴埋め（N か所）
次の一歩
  ナレーションを作るときは「ナレーションを作って」と言ってください（yt-narration）
```

---

## やってはいけないこと

- 公開・投稿・アップロードをしない
- 他人の文章・画像・音楽・動画を使わない（引用のルールが分からないなら使わない）
- 体験談・数字・口コミを作り話で埋めない
- 「必ず稼げる」「誰でも」「確実に」など、うそになる言い方をしない
- 医療・法律・税金・投資の話は「最終判断は専門家や公式情報で」と台本の中で一言添える
